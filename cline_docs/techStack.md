# Tech Stack

## Tecnologías Principales
- **Frontend**: HTML5 Semántico, CSS3 Moderno, Tailwind CSS, JavaScript Moderno (ES6+ Modules)
- **Componentes de UI**: Iconografía SVG limpia (Lucide Icons), Modales accesibles, Tabs responsivos
- **Almacenamiento Local**: `localStorage` para persistencia inmediata de pruebas sin requerir bases de datos pesadas en local
- **Servidor Local de Pruebas**: Node.js Nativo (`http` / `fs` / `path`) sin dependencias externas para ejecución inmediata en Windows/Linux/Mac
- **Roadmap Backend (Fase 2)**:
  - Database: PostgreSQL / Supabase
  - Auth: JWT / Supabase Auth
  - WhatsApp: WhatsApp Business Cloud API / Webhooks
  - Pagos: Mercado Pago SDK / Webhooks de transferencias bancarias
